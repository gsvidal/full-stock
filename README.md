# Full Stock 
## (Última actualización de este documento al 09/11/25)

## Live demo [aquí](https://www.gonzalovidal.dev/full-stock/about.html)

Proyecto académico estático construido con **HTML** y **CSS**, que incluye las páginas:
- `about.html` – Quiénes somos  
- `privacy.html` – Política de Privacidad  
- `terms.html` – Términos y Condiciones  

---

## 🧭 Clonar el repositorio

### Opción 1: HTTPS
```bash
git clone https://github.com/gsvidal/full-stock.git
```

### Opción 2: SSH
```bash
git clone git@github.com:gsvidal/full-stock.git
```

Luego entra al directorio:
```bash
cd full-stock
```

---

## 🚀 Ejecutar el proyecto

### Opción 1: Usando Live Server (recomendada)
1. Abre la carpeta `full-stock` en **VS Code**.  
2. Instala la extensión **Live Server** (autor: Ritwick Dey).  
3. Haz clic en **Go Live** (abajo a la derecha).  
4. Abre cualquier archivo `.html` (por ejemplo, `about.html`). (Ya que aún no contamos con index.html) 
5. El sitio se abrirá automáticamente en tu navegador.  

### Opción 2: Manualmente
- Abre cualquier archivo `.html` directamente en tu navegador (doble clic).
